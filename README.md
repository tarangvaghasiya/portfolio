# Tarang Vaghasiya — Personal Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Project files

- `index.html` — page content and sections
- `style.css` — dark premium / neon purple design and responsive layouts
- `script.js` — mobile navigation, active navigation state and current year
- `assets/` — add your personal image and certificates here

## Run locally

1. Download and extract the project ZIP.
2. Open the `tarang-portfolio` folder in VS Code.
3. Add your profile photo as `assets/profile.jpg`.
4. Open `index.html` in a browser, or use the VS Code Live Server extension.

No build tools or package installation are required.

## Add your assets

- Profile photo: `assets/profile.jpg` (added)
- PixelRush certificate: `assets/pixelrush-certificate.png` (added)
- Orvo Innovation certificate: `assets/orvo-certificate.png` (added)

Both uploaded certificates are displayed in the Achievements section. Click either certificate card to open the full image.

## Deploy to Vercel

1. Create a GitHub repository and upload the contents of this folder.
2. Sign in to Vercel with GitHub.
3. Select **Add New → Project**, then import the repository.
4. Keep the framework preset as **Other**.
5. Leave the build command and output directory empty; deploy the static site.
6. Vercel will provide a free `vercel.app` URL.

## Before publishing

- Check that the displayed phone number and email are the contact details you want public.
- Add screenshots when ready. The current project visuals are CSS-made preview illustrations, not screenshots of the actual applications.
